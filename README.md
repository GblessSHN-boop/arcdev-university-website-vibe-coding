# ARCDEV University Website Vibe Coding

Website resmi konseptual Universitas ARCDEV.

Project ini difokuskan sebagai website universitas modern, bilingual, SEO-ready, dan admission-oriented.

## Main Scope

- Homepage premium
- Profil universitas
- Fakultas dan program studi
- Penerimaan mahasiswa baru
- Beasiswa
- Kehidupan kampus
- Newsroom
- Portal akses cepat
- Bahasa Indonesia dan Inggris

## Tech Direction

- CSS
- JavaScript

- Alpine.js
- GSAP
- Lenis
- Swiper
