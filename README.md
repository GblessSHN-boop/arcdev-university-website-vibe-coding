# ARCDEV University Website Vibe Coding

## English

**ARCDEV University Website Vibe Coding** is a frontend-only experimental website project designed as a modern digital presence for a conceptual university named **ARCDEV University**.

This project focuses on building a clean, professional, bilingual, SEO-ready, and admission-oriented university website. The website structure is prepared to support institutional profile pages, faculty pages, study program pages, admissions information, scholarship information, campus life content, newsroom content, and quick access digital portal links.

This repository is not an application, not a mobile app, and not a backend system. It is a website-only frontend experiment that explores how a university website can be structured, presented, documented, and improved through a vibe coding workflow.

## Indonesia

**ARCDEV University Website Vibe Coding** adalah proyek eksperimen website frontend-only yang dirancang sebagai wajah digital modern untuk universitas konseptual bernama **Universitas ARCDEV**.

Repository ini bukan aplikasi, bukan mobile app, dan bukan sistem backend. Project ini adalah eksperimen website-only pada sisi frontend untuk menguji bagaimana website universitas dapat dirancang, disusun, didokumentasikan, dan dikembangkan melalui pendekatan vibe coding.

## What is Vibe Coding in This Project?

In this repository, **vibe coding** refers to an experimental web development workflow where the developer builds a project by combining idea exploration, visual direction, AI-assisted planning, manual code organization, iterative improvement, Git workflow, and structured documentation.

The purpose is not to randomly generate code. The purpose is to use AI as a development partner while the developer still controls the architecture, folder structure, naming system, content direction, repository workflow, and final project decisions.

In this project, vibe coding is used to:

- Explore university website concepts.
- Design a frontend-only academic website architecture.
- Prepare bilingual page structure.
- Build reusable layout and component folders.
- Document the project professionally through GitHub.
- Practice Git and GitHub workflow.
- Prepare the project for Astro, Tailwind CSS, animation, and future frontend enhancement.
