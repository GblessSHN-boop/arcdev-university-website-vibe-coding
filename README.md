# ARCDEV University Website Vibe Coding

## English

ARCDEV University Website Vibe Coding is a frontend-only experimental website project designed as a modern digital presence for a conceptual university named ARCDEV University.

This project focuses on building a clean, professional, bilingual, and admission-oriented university website. The website structure is prepared to support institutional profile pages, faculty pages, study program pages, admissions information, scholarship information, campus life content, newsroom content, and quick access digital portal links.

The project is currently limited to the frontend layer. Backend development, database integration, authentication, content management system, and production deployment will be developed in later phases.

## Indonesia

ARCDEV University Website Vibe Coding adalah proyek eksperimen website frontend-only yang dirancang sebagai wajah digital modern untuk universitas konseptual bernama Universitas ARCDEV.

Proyek ini berfokus pada pembangunan website universitas yang bersih, profesional, bilingual, dan berorientasi pada penerimaan mahasiswa baru. Struktur website disiapkan untuk mendukung halaman profil institusi, fakultas, program studi, penerimaan mahasiswa baru, beasiswa, kehidupan kampus, newsroom, dan akses cepat menuju layanan portal digital.

Pada tahap ini, proyek hanya mencakup bagian frontend. Backend, database, autentikasi, sistem manajemen konten, dan deployment produksi akan dikembangkan pada fase berikutnya.

## Main Scope

- Premium university homepage
- Institutional profile
- Faculty and study program pages
- Admissions center
- Scholarship information
- Campus life section
- ARCDEV Newsroom
- Quick access digital portal
- Indonesian and English language structure
- SEO-ready page organization
- Mobile-first website structure

## Technology Direction

This repository is prepared for the following frontend stack:

- HTML
- CSS
- JavaScript
- Astro
- Tailwind CSS
- Alpine.js
- GSAP
- Lenis
- Swiper
- Lucide Icons

The selected stack is intended to support a fast, structured, responsive, and maintainable website experience.

## Current Status

Current phase: frontend starter structure.

The repository already contains the initial folder organization, base layout files, homepage components, bilingual page folders, data files, global styling, documentation files, copyright notice, and project notice.

## Project Purpose

This project is created for learning, experimentation, frontend architecture practice, website concept development, and portfolio documentation. It is not an official university website unless formally authorized and deployed by the rightful institution.
